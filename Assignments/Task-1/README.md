## Overview

This assignment contains solutions for four tasks demonstrating the core Python data structures in an e-commerce inventory scenario:
- Lists: Ordered and mutable collection of products.
- Tuples: Immutable records for storing product snapshots.
- Sets: Unordered collections used for unique categories and duplicate removal.
- Dictionaries: Key-value mappings for product prices and category groupings.

All solutions use pure standard Python without any third-party libraries.

---

## File Structure

- `task1_collections.py`: Demonstrates creating a product list, accessing items by index, appending items, and working with a product tuple. Also includes the extra exercise for updating tuple data via list conversion.
- `task2_categories.py`: Creates a set of categories from a parallel list, shows adding new items and duplicate handling, tests category membership, and gets the count of unique categories.
- `task3_pricing.py`: Creates a product price dictionary, adds/updates prices, safely removes products with validation, calculates the average price, and identifies the cheapest and most expensive products.
- `task4_combined.py`: Combines products, prices, and categories into a catalog list of tuples, creates a category-to-products dictionary, and finds the category containing the highest number of items.
- `README.md`: Project description and execution guide.
